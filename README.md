# Research Agent Skills: 自动化经济统计科研智能体流水线

本项目提供了一套高度模块化、面向工业级学术生产的科研智能体（AI Agent）技能库（Skills）与中央编排指南。本系统专为**经济学、计量经济学、量化金融及大宗商品/能源市场**方向的研究人员设计。通过对底层多源数据资产的解构与逻辑死锁，系统可实现从文献地毯式检索、数理边界硬对齐、实证代码双轨产出，到最终高密度学术论文总装的全流程全自动/半自动作业。

---

## 1. 基础环境配置

构建该科研工作流，需要依赖以下两个核心工具：

### 1.1 下载与配置 Obsidian
作为个人知识库、文献阅读管理以及全自动成果沉淀的核心前端展示区。请前往 Obsidian 官网下载对应系统的最新版本，并建立一个专门的科研 Vault。

### 1.2 下载与配置 Antigravity IDE
作为运行智能体、执行底层系统级 IO 指令与自动化脚本的中央核心引擎。
* **网络与地区限制提示**：Antigravity IDE 在初始化与配置过程中大概率会遇到地区访问与域名路由限制问题。请确保你的本地网络环境已正确配置好相应的代理规则或全局路由。
* **安装验证标准**：安装完成后，请务必在 IDE 的对话终端内与智能体进行一次基础交互（例如输入 `Hello`）。**只有当智能体成功返回结构化回答时，才证明 IDE 的底座网络配置与运行环境真正安装成功。**

## 2. 必备基础 Skills 安装

在确保 Antigravity IDE 能够正常对话后，需要先为其装配基础的全网检索与通用学术处理能力。请直接在 Antigravity IDE 的终端对话框中向智能体发送以下指令：

> "请帮我下载 `gpt-researcher` 和 `scientific-agent-skills` 这两个 skill。"

智能体会自动识别指令，并在底层调用本地环境完成这两个前置依赖能力库的拉取、封装与安装。

## 4. 自动化科研流水线标准操作手册 (SOP)

### 📥 阶段 0：规划本地物理路径
在与智能体对话前，请确保你在本地（或 Obsidian Vault 中）建立并获取以下三个文件夹的绝对路径：
1. **成果区路径 (`root_path`)**：存放最终论文全文和各个阶段生成的 Markdown 过程文档。
2. **原始数据存放区 (`data_source_path`)**：存放前期不完整、待孵化或探索性的原始数据集。
3. **模型数据/实证生产区 (`code_and_images_path`)**：专门存放运行代码、交互式 `.ipynb` 脚本、完整数据集以及高清图表物理输出的专属闭环核心生产区。

### 🟢 阶段 1：唤醒中央矩阵引擎与数据验资
你需要使用极其严苛的指令格式来唤醒超级中央编排引擎 `Research_Pipeline_Matrix_Engine` 并注入你的全局变量。
**请将以下指令中的括号内容替换为你电脑的真实物理路径，并发送给智能体：**

> "调用 Research_Pipeline_Matrix_Engine.skill，开始课题：[你的研究主题，例如：电力市场]的分析，论文成果路径存储到：[成果区绝对路径]，原始数据源路径指定为：[原始数据存放区绝对路径]，实证代码与图片生产区指定为：[模型数据/实证生产区绝对路径]"

* **自适应路由分支**：引擎接收指令后会立刻物理拦截（Intercept）执行流，严禁直接生成任何文档。智能体会向你抛出数据完整性问询：
  > 『📢 请问您目前是否有完整的数据？  
  > 👉 选项 [A] 有完整数据（请将数据放入“模型数据”文件夹，我将仅基于您的已有数据进行建模，不推荐 any 外部多余变量）  
  > 👉 选项 [B] 没有/仅有部分数据（请将数据放入“原始数据”文件夹，我将自主为您匹配设计前沿计量模型，并给出后续数据抓取建议）  
  > 请直接回复 [A] 或 [B]：』
* **你的操作**：根据真实情况直接回复 **[A]** 或 **[B]**。系统会据此锁定 `has_complete_data` 变量（`true`/`false`），自动切换不同的计量建模与发散推理策略。

### 🟡 阶段 2：遵循级联问询，步步推进 (文献与理论构建)
本系统在编排层内置了严酷的【单步确认铁律】。每当在本地成果区输出任意一个阶段性成果文件后，智能体都会立刻挂起执行流，绝不自主向下跨越。
* **分支操作语法**：每一步结束时，智能体都会抛出交互问询：
  * **用户回复“是”**（或发出确认口令，如 `开始生成 1.2【研究框架_理论版.md】`）：流水线自动流转并加载下一阶段。
  * **用户回复“否”**：智能体进入 Standby 挂起状态，并打印提示引导：  
    > 『🛑 明白，已为您挂起流水线。当 [当前步骤] 【[当前文件].md】完善后，请明示：开始生成 [下一步骤]【[下一步文件].md】』

### 🔴 阶段 3：代码双轨产出与人类物理介入 (实证分析)
当流水线稳步推进到步骤 `3.2` 时，智能体将对齐完整数据集实现两轨产出：将 `建模.md` 写入成果区，同时在代码区生成物理可执行的 `[英文简称]_Empirical.ipynb`。
* **人类干预挂起**：此时流水线强制挂起，智能体提示用户将补齐后的【完整数据】物理放入模型数据生产区。
* **你的操作**：
  1. 离开智能体终端，打开你的本地 Python 环境（如 Jupyter Notebook / VS Code）。
  2. 运行智能体为你编写好的 `.ipynb` 脚本（脚本首个单元格已内置 Mac OS 和 Windows 自适应中文字体支持与负号显示补丁代码 `Arial Unicode MS`/`SimHei`）。
  3. 观察并确保回归模型跑通，高清实证图表（已自动配置 `bbox_inches='tight'` 完整防裁切）和回归统计矩阵真实落地在 `images/` 路径中。
  4. 确认得出真实结果后，回到对话框明示：**“开始生成 3.3【模型结果.md】”**。
* **断言动态激活**：步骤 3.3 将读取你跑出的 `.ipynb` 真实输出结果（如 AIC/BIC 滞后阶数、统计量、p值等），去匹配步骤 1.2 中的 IF/ELSE 反回机制，【一字不差】地调用法典中对应的学术结论进行事实陈述，并生成标准的三线表。

### 🟣 阶段 4：终极收官总装与格式洗牌 (论文定稿)
* **你的操作**：在终端发出指令：**“开始生成 4.1【论文全文.md】”**。
* **总装与学术清洗**：智能体全面接入前期资产，严格清洗并替代所有非学术化、拟人化或戏剧化的词汇：
  * *“资金极度疯狂/放水”* ➔ **流动性极度充裕/系统性流动性冲击**
  * *“价格暴涨暴跌/狂热”* ➔ **资产价格的非线性投机性偏离/结构性突变**
  * *“市场很不正常/失灵”* ➔ **市场微观结构扭曲/适应性效率下降/弱式有效性间歇性丧失**
  * *“现货企业被洗出局”* ➔ **理性产业套保资金规模因追加保证金压力而发生非自愿性缩减**
  * *“价格回归的弹簧断了”* ➔ **理性套利边界失效与期现货价格收敛机制受阻**
* **提炼与洗牌**：逆向提炼饱含核心参数的 250-300 字脱水摘要。自动联动运行 `Format_Standard.skill` 技能校准一二级标题序号，洗牌参考文献至国内顶刊极简 `[J]` 格式，全面净化流水线痕迹。
